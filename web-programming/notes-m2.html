Web Programming — Module 2 Lecture Notes Introduction to CSS and JavaScript Page 2 of 22 1. Introduction to CSS, CSS3, Basic Syntax and Structure, Inline Styles 1.1 What is CSS? CSS (Cascading Style Sheets) is a style-sheet language used to describe the presentation of an HTML document — colours, fonts, spacing, layout — while HTML remains responsible only for structure and meaning. Separating structure (HTML) from presentation (CSS) makes sites easier to maintain, lets one stylesheet skin many pages consistently, and lets the same HTML be restyled for print, mobile, or accessibility needs without touching markup. • Cascading refers to the algorithm that resolves conflicts when multiple rules could apply to the same element, based on specificity, source order, and importance (see Module 1 recap: inline > id > class > element). • CSS was first proposed by Håkon Wium Lie in 1994 and became a W3C Recommendation (CSS1) in 1996. • CSS2 (1998) added positioning and media types; CSS3, from the early 2000s onward, split the specification into independent modules (Selectors, Flexbox, Grid, Animations, etc.), each versioned and evolving separately — this is why we now speak of individual CSS3 modules rather than one single CSS3 document. 1.2 CSS3 — Modular Evolution Unlike CSS1/CSS2 which were single monolithic specifications, CSS3 is organised as a collection of independent modules that can progress through standardisation at their own pace. This is why browsers can support one CSS3 feature (e.g. Flexbox) fully while another (e.g. a newer Grid feature) is still experimental. CSS3 Module Adds Selectors Level 3/4 Attribute, pseudo-class and combinator selectors (see Section 3) Box Model box-sizing property to change how width/height are calculated Backgrounds and Borders Multiple backgrounds, rounded corners (border-radius), box-shadow Flexible Box Layout (Flexbox) One-dimensional flexible layouts Grid Layout Two-dimensional grid-based layouts Media Queries Responsive styling based on viewport/device characteristics Transitions & Animations Smooth property changes and keyframe-based animation without JavaScript 1.3 Basic CSS Syntax A CSS rule (rule-set) consists of a selector, which targets HTML element(s), followed by a declaration block in curly braces containing one or more declarations. selector { property: value; property: value; }

Embedded Style Sheets and Linking External Style Sheets 2.1 Embedded (Internal) Style Sheets An embedded stylesheet is placed inside a <style> element within the <head> of the HTML document. Rules apply to the whole document (or the elements matched by their selectors), not just a single tag. <head> <meta charset="UTF-8"> <title>My Page</title> <style> body { font-family: Arial, sans-serif; background-color: #f5f5f5; } h1 { color: #5E3E8E; } .highlight { background-color: yellow; } </style> </head> • Useful for single-page documents or page-specific overrides, but the CSS is not reusable across multiple pages — every page needs its own copy. 2.2 External Style Sheets An external stylesheet is a separate .css file linked into the HTML document using the <link> element, placed in the <head>. This is the recommended approach for real projects. <!-- In every HTML page that should use these styles --> <link rel="stylesheet" href="styles/main.css">

/* Contents of styles/main.css */ body { font-family: Arial, sans-serif; margin: 0; } h1 { color: #5E3E8E; } Attribute Purpose rel="stylesheet" Tells the browser this linked resource is a stylesheet. href Path/URL to the .css file (relative or absolute). type="text/css" Optional in HTML5 (text/css is assumed by default). media Restricts when the stylesheet applies, e.g. media="print" for print-only styles.

Box Model and Text Flow, Responsive CSS, Viewport and Media Queries 5.1 The CSS Box Model Every HTML element is rendered as a rectangular box made of four nested layers, from the inside out: content, padding, border, and margin. ┌─────────────────────────────┐ │ margin │ │ ┌───────────────────────┐ │ │ │ border │ │ │ │ ┌─────────────────┐ │ │ │ │ │ padding │ │ │ │ │ │ ┌───────────┐ │ │ │ │ │ │ │ content │ │ │ │ │ │ │ └───────────┘ │ │ │ │ │ └─────────────────┘ │ │ │ └───────────────────────┘ │ └─────────────────────────────┘ Layer Purpose content The actual text/image/etc.; sized by width and height. padding Transparent space between the content and the border (inside the element's background). border A visible (or invisible) line surrounding the padding: border-width, border-style, border-color. margin Transparent space outside the border, separating this element from its neighbours; margins can collapse between adjacent block elements. .box { width: 300px; padding: 20px; border: 5px solid #5E3E8E; margin: 15px; } /* Rendered total width = 300 + 202 + 52 + 15*2 = 380px by default */ 5.1.1 box-sizing * { box-sizing: border-box; } • content-box (default): width/height apply to the content only; padding and border are added on top, making the rendered box larger than the declared width. • border-box: width/height include padding and border, so the declared width IS the final rendered width — much easier to reason about, and the near-universal modern default via a * { box-sizing: border-box; } reset.

Property Purpose display block, inline, inline-block, flex, grid, none — governs how the box participates in layout. float left/right — lets an element be pushed to one side while text flows around it (classic technique now largely superseded by Flexbox/Grid for layout, but still valid for text- wrap-around-image). clear Stops an element from wrapping around a floated element (clear: both;). text-align left, right, center, justify — horizontal alignment of inline content within its box. white-space normal, nowrap, pre — controls whitespace collapsing and line wrapping. overflow visible, hidden, scroll, auto — behaviour when content exceeds its box. 5.3 Basics of Responsive CSS Responsive design means a page automatically adapts its layout to different screen sizes and devices (desktop, tablet, phone) using flexible units, flexible layout models, and conditional CSS rather than building separate sites per device. • Fluid layouts: use relative units (%, vw, vh, em, rem) instead of fixed pixels so elements scale with the viewport. • Flexible images: img { max-width: 100%; height: auto; } so images shrink to fit their container instead of overflowing. • Mobile-first approach: write base styles for small screens first, then progressively add rules for larger screens inside min-width media queries. 5.4 The Viewport meta Tag Before applying responsive CSS, the HTML document must declare its viewport, or mobile browsers will render the page at a fixed desktop-like width (e.g. 980px) and then zoom out — defeating responsive CSS entirely. <meta name="viewport" content="width=device-width, initial-scale=1.0"> Directive Meaning width=device-width Sets the layout viewport width to match the device's actual screen width in CSS pixels. initial-scale=1.0 Sets the initial zoom level when the page first loads (1.0 = no zoom). maximum-scale / user-scalable Can restrict pinch-zoom (use cautiously — restricting zoom can harm accessibility). 5.5 Media Queries A media query applies a block of CSS rules only when the browser/device matches given conditions (viewport width, orientation, resolution, print vs screen).

Web Programming — Module 2 Lecture Notes Introduction to CSS and JavaScript Page 14 of 22 6. Introduction to JavaScript — Scripting, Programming Fundamentals, prompt Dialogs 6.1 What is JavaScript? JavaScript (JS) is a lightweight, interpreted, dynamically-typed scripting language that runs primarily in web browsers, giving HTML pages behaviour and interactivity — reacting to clicks, validating forms, updating content without reloading the page, and much more. Alongside HTML (structure) and CSS (presentation), JavaScript is the third pillar of front-end web development. • Created by Brendan Eich in 1995 (originally named Mocha, then LiveScript, then JavaScript) for Netscape Navigator. • Standardised as ECMAScript (ES) by ECMA International; 'JavaScript' is the common name, 'ECMAScript' is the formal specification name. • Despite the similar name, JavaScript is unrelated to Java — the naming was a marketing decision in the mid-1990s. • Client-side scripting: JS traditionally executes in the user's browser (as opposed to server-side languages like PHP); Node.js later extended JS to run outside the browser as well. 6.2 Including JavaScript in a Web Page <!-- Inline (avoid for anything beyond trivial handlers) --> <button onclick="alert('Hi')">Click</button>

<!-- Embedded, inside <script> tags --> <script> console.log("Page loaded"); </script>

<!-- External file (recommended) --> <script src="app.js" defer></script> • defer: script downloads in parallel with HTML parsing and executes only after parsing finishes, preserving order — the recommended default for most scripts. • async: downloads in parallel but executes as soon as it's ready, potentially before HTML parsing finishes — order relative to other scripts is not guaranteed. • Without defer/async, a <script> in the middle of the page blocks HTML parsing until the script finishes downloading and executing. 6.3 Programming Fundamentals of JavaScript 6.3.1 Variables let age = 20; // block-scoped, reassignable const name = "Justin"; // block-scoped, cannot be reassigned var legacy = true; // function-scoped, older syntax (avoid in new code)
