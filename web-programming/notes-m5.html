MODULE V · 1 HR TOPIC What is JSON & Why It Matters 20CST461 1 JSON = JavaScript Object Notation A lightweight, text-based format for representing structured data — readable by humans and easy for machines to parse. Despite the name, it's used by virtually every programming language, not just JavaScript. 2 Why it replaced XML for most APIs JSON is far less verbose than XML (no closing tags), maps directly onto common data structures (objects, arrays) that most languages already have, and parses faster. 3 Where it shows up API responses, configuration files, the request/response bodies of almost every modern web service — including the database rows from Module IV, once converted. 4 What it is NOT JSON is a data format, not a programming language — it has no functions, no comments, no logic. It only describes data. Web Programming | Saintgits College of Engineering 2

MODULE V · 1 HR TOPIC JSON Syntax — Objects & Arrays 20CST461 JSON is built from exactly two structures: objects (key-value pairs) and arrays (ordered lists) — everything else nests inside these. • { } defines an object: unordered key-value pairs • [ ] defines an array: an ordered list of values • Keys are ALWAYS double-quoted strings — single quotes are invalid • No comments and no trailing commas — strict syntax, unlike JavaScript object literals JSON { "name": "Anu", "age": 20, "isActive": true, "marks": [88, 92, 79] } Web Programming | Saintgits College of Engineering 3

MODULE V · 1 HR TOPIC Nested JSON — Objects Within Objects 20CST461 Real-world JSON is usually nested several levels deep — objects containing arrays of objects, and so on. • Any value (including another object or array) can sit inside an object or array • Nesting models real relationships: a student HAS an address, HAS a list of marks • Indentation is just for human readability — it has no effect on parsing • This is the shape API responses typically take, including ones built by Laravel later in this module JSON { "name": "Anu", "address": { "city": "Kottayam", "pin": "686532" }, "courses": [ { "code": "20CST461", "title": "Web Programming" } ] } Web Programming | Saintgits College of Engineering 5

MODULE V · 1 HR TOPIC What is JSON Schema? 20CST461 1 The problem it solves JSON itself has no built-in way to say 'this field is required' or 'this must be a number' — JSON Schema is a separate JSON document that describes those rules for another piece of JSON. 2 What it can specify Required fields, expected data types per field, value constraints (minimum/maximum, string patterns), and the structure of nested objects/arrays. 3 Why it matters for APIs Before trusting incoming JSON (e.g. from a form submitted via JavaScript, or another service), a schema lets you validate its shape automatically instead of writing manual checks for every field. 4 Where it's used API documentation tools, request validation libraries, and configuration file validation — not required for every JSON use case, but valuable wherever JSON crosses a trust boundary. MODULE V · 1 HR TOPIC json_encode() — PHP to JSON 20CST461 PHP's built-in json_encode() converts a PHP array or object directly into a JSON-formatted string. • json_encode($value) returns a JSON string built from the given PHP value • PHP associative arrays become JSON objects automatically • PHP indexed arrays become JSON arrays automatically • JSON_PRETTY_PRINT flag formats the output with readable indentation PHP <?php $student = [ "name" => "Anu", "marks" => [88, 92, 79] ]; echo json_encode($student); echo json_encode($student, JSON_PRETTY_PRINT); ?> Web Programming | Saintgits College of Engineering 7

MODULE V · 1 HR TOPIC json_decode() — JSON to PHP 20CST461 json_decode() does the reverse — turning a JSON string back into usable PHP data. • json_decode($jsonString) returns a PHP object by default • json_decode($jsonString, true) returns an associative array instead — usually more convenient • json_last_error() checks whether decoding actually succeeded • Common use: reading a JSON request body sent by a JavaScript fetch() call PHP <?php $json = '{"name":"Rahul","marks":[72,80]}'; $asObject = json_decode($json); echo $asObject->name; $asArray = json_decode($json, true); echo $asArray["name"]; ?> Web Programming | Saintgits College of Engineering 8

MODULE V · 1 HR TOPIC Putting It Together: A Database Row as JSON 20CST461 Combining Module IV's database pattern with json_encode() turns a query result into a ready-to-use API response — no HTML involved at all. • Fetch all rows into a plain PHP array first • json_encode() the whole array at once, after the loop • header("Content-Type: application/json") tells the client what kind of response this is • This is the foundation of building an API endpoint instead of an HTML page PHP <?php header("Content-Type: application/json"); $result = mysqli_query($conn, "SELECT name, marks FROM students"); $students = []; while ($row = mysqli_fetch_assoc($result)) { $students[] = $row; } echo json_encode($students); ?> Web Programming | Saintgits College of Engineering 9

MODULE V · 1 HR TOPIC What is Laravel & Why Use a Framework? 20CST461 1 The problem at scale Modules III and IV's hand-written connect → query → loop → render pattern works, but repeating it across dozens of pages in a real application gets repetitive and error-prone fast. 2 What Laravel provides A free, open-source PHP framework that supplies routing, database access (via an ORM), templating, authentication, and project structure out of the box — so common problems are solved once, consistently. 3 'Framework' vs. 'library' A library (like a single PHP function file) is something your code calls. MODULE V · 1 HR TOPIC Middleware — Filtering Requests 20CST461 1 What middleware does Code that runs BEFORE a request reaches its controller (or after the response is built) — a filtering/processing layer that wraps around the actual request handling. 2 Common uses Checking whether a user is logged in (auth middleware), logging requests, checking permissions, or rate-limiting how often an endpoint can be called. 3 Applying middleware to a route Route::get('/dashboard', ...)->middleware('auth'); — this single line ensures the dashboard route only runs its controller logic for logged-in users. 4 Why it's separate from the controller Keeping this logic out of the controller means the same check (e.g. 'is logged in') doesn't need to be repeated inside every single controller method that needs it. MODULE V · 1 HR TOPIC Connecting Routes to Controllers 20CST461 Here's the full picture: a route, protected by middleware, pointing to a controller method. • The route declares the URL and which controller method should run • Middleware (if any) runs first, and can stop the request before it reaches the controller • The controller method runs last, doing the actual work • This three-piece chain — route, middleware, controller — handles every request in a Laravel app PHP (Laravel) // routes/web.php Route::get('/students', [StudentController::class, 'index']) ->middleware('auth'); // app/Http/Controllers/StudentController.php public function index() { $students = Student::all(); return view('students.index', compact('students')); } Web Programming | Saintgits College of Engineering 17
