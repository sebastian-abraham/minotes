ANSWERS — SET 1

1.1 ε-closure (Exp 5)#

1. Read n, the number of states.
2. Read the n×n epsilon matrix ε, where ε[i][j]=1 means an ε-move i→j.
3. Initialise the closure matrix to 0.
4. For each state s = 0 .. n-1: call findClosure(s, s).
5. For each s, print every j with closure[s][j]=1 as E-closure(qs).
6. Stop.

findClosure(state, current):
1. Mark closure[state][current] = 1.
2. For each i = 0 .. n-1:
     if ε[current][i] = 1 AND closure[state][i] = 0:
         findClosure(state, i).

Two-parameter trick: state is whose closure we're computing (fixed); current is where the walk is now (changes). The closure[state][i] = 0 test is what stops a cycle of ε-moves recursing forever.

1.2 NFA → DFA (Exp 7)#

1. Read n, m, the input symbols, and the NFA transition table
   (per state and symbol: a count followed by the destination states).
2. Create DFA state 0 = { q0 } and add it to the set list.
3. For each DFA state i in the set list (list grows while looping):
     for each input symbol j:
       a. temp = union of δ(p, j) over every NFA state p in DFA state i, duplicates removed.
       b. Sort temp, so identical sets are stored in the same order.
       c. dfa[i][j] = addSet(temp)   — reuse the existing index if this set is already a DFA state.
4. Print the DFA table, labelling each state by its set, e.g. {q1,q2}.
5. Stop.

sameSet(a,b) : are two sets identical?
findSet(s)   : index of this set if already a DFA state, else −1
addSet(s)    : findSet(s) if it exists, otherwise append it and return the new index

1.3 FIRST / FOLLOW (Exp 8)#

FIRST(X):
1. X terminal      → FIRST(X) = { X }; return.
2. X non-terminal  → for each production X → Y1 Y2 ... Yk:
     a. add FIRST(Y1) − {ε} to FIRST(X);
     b. if Y1 can derive ε, add FIRST(Y2) − {ε}, and continue for Y3 ...
     c. if every Yi can derive ε, add ε to FIRST(X).

FOLLOW(A):
1. If A is the start symbol, add $ to FOLLOW(A).
2. For each production B → α A β:
     a. add FIRST(β) − {ε} to FOLLOW(A);
     b. if β derives ε (or β is empty), add FOLLOW(B) to FOLLOW(A).

MAIN:
1. Read n and the n productions as strings (use # for ε).
2. For each non-terminal on a left-hand side, compute and print FIRST.
3. For each non-terminal, compute and print FOLLOW.

Implementation notes worth saying: a set is stored as a plain char string and add() appends only if absent (that is the dedupe); FOLLOW recurses on the LHS of the current production in the "β can vanish" case — that is step 2(b) of the theory, not an implementation shortcut.

1.4 Shift-reduce (Exp 10)#

1. Read the input string. top = −1 (empty stack).
2. For each input character, left to right:
   a. SHIFT: push the character; print the stack.
   b. REDUCE repeatedly while the top of the stack matches a RHS:
        top = 'i'                → replace by 'E'      (E → i)
        top three = E '+' E      → replace by 'E'      (E → E+E)
        top three = E '*' E      → replace by 'E'      (E → E*E)
      Print every reduction.
3. After the input ends, keep reducing until a full pass performs no reduction
   (top unchanged before and after the pass).
4. If the stack holds exactly one symbol and it is 'E' → "String Accepted", else "String Rejected".

Detail for a mark: after every push/pop write stack[top+1] = '\0' so the stack can be printed as a string in the trace.

2.2 rdp.c — verified run#

(i+i)*i → String is accepted · i+*i → Invalid string

Shape: char input[100]; int pos = 0; and five functions E, Eprime, T, Tprime, F plus error() which prints "Invalid string" and exit(0). Accept test in main: input[pos] == '\0' after E(). Eprime() = if (input[pos]=='+') { pos++; T(); Eprime(); } and nothing else — the absent else is the ε-production. F() = 'i' → pos++ · '(' → pos++, E(), expect ')' → pos++ · anything else → error().

2.3 intermediate.c — verified run#

Input a+b*c printed exactly:

Intermediate Code:
t1 = b * c
t2 = a + t1

Shape: two char stacks (operand[ ][ ] of strings, opstack[ ]), int temp = 1, precedence() returning 2 for * /, 1 for + -, 0 otherwise; generate() printing "%s = %s %c %s". Reduction condition while (top_op >= 0 && precedence(opstack[top_op]) >= precedence(ch)) — then pop b first, a second, sprintf(result,"t%d",temp++), push result.

ANSWERS — SET 3 (viva)

3.1 To detect where the token ends. That character belongs to the next token, so it is pushed back with ungetc() — otherwise it is lost and the next token is misread.

3.2 Both are possible, but lex applies longest match first, then the earlier rule on a tie. Same length, so the keyword rule wins because it is written first.

3.3 The length of the matched text (yytext). Exp 3 uses it to count characters without looping: characters += yyleng.

3.4 lex recognises tokens (regular expressions); yacc checks their order against a grammar (context-free rules). lex feeds yylex(), yacc consumes it in yyparse().

3.5 It also writes the token-definition header y.tab.h, which the .l file includes so the two halves agree on token numbers.

3.6 The lex runtime library (yywrap, the input buffer). System V lex ships it as libl → -ll; flex ships libfl → -lfl. On this machine only libfl exists.

3.7 yacc is LALR — bottom-up — and left recursion lets it consume input with a bounded stack; it also encodes "an identifier followed by one more letter is still an identifier" directly. Right recursion would grow the stack for every symbol.

3.8 123abc starts with DIGIT, and the rule identifier : LETTER | identifier LETTER | identifier DIGIT can only *start* from LETTER. No derivation exists, so yyerror() fires.

3.9 ε-closure = the state plus everything reachable by ε-moves, and ε-moves can chain, so it is naturally recursive. The closure[state][i] == 0 check visits each state once, so cycles terminate.

3.10 δ'(q, a) = ε-closure( ∪ over p ∈ ε-closure(q) of δ(p, a) ) — teleport freely, read the symbol, teleport freely again.

3.11 Exp 5 computes it; Exp 6 takes it as input. That is the pipeline: 5 → 6 → 7.

3.12 A set of NFA states — "the NFA could be in any of these right now". The subset construction makes each such set one state of the deterministic machine.

3.13 Without sorting, {q1,q2} and {q2,q1} are different arrays, sameSet says no, and the DFA grows duplicate states forever.

3.14 Sets are appended to the list and the loop index keeps advancing, so a set discovered at index 3 is processed when the loop reaches index 3 in the same pass.

3.15 FIRST(X): terminals that can begin a string derived from X. FOLLOW(A): terminals that can appear immediately after A (plus $ if A can end the input).

3.16 ε is awkward to type on a terminal, so # stands in for it in the production strings.

3.17 It is the absence of a match: Eprime() tests for +; if it isn't there, the function returns without consuming anything. That silent return is the ε-production.

3.18 Because * lives one level deeper — F is inside T, T is inside E. Deeper nesting is applied first, so * binds tighter.

3.19 Shift: move one input symbol onto the stack. Reduce: replace a RHS on top of the stack by its LHS. Bottom-up, vs recursive descent's top-down.

3.20 To detect "no progress". If a full pass leaves top unchanged, no rule applies and further passes would loop forever.

3.21 Operands come off a stack, so the last one pushed is the right operand. Popping b first, then a, keeps a op b in source order — getting it backwards prints t1 = c * b.

3.22 >= makes equal precedence reduce immediately, so operators of the same precedence associate left to right — a-b-c becomes (a-b)-c, which is what C does.

3.23 It reduces i→E, then E*E→E, then E+E→E — i.e. i+(i*i), which matches precedence. The grammar E→E+E|E*E|i is ambiguous, and this reduce-as-soon-as-possible order happens to pick the precedence-correct parse for this input; it is not guaranteed in general.

3.24 No. lex is the traditional name; on a flex machine it is the same tool (often a symlink or wrapper). The generated file and the -lfl flag are what change, not your source.
